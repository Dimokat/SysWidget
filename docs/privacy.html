Privacy policy

Last updated: November 22, 2026

SysWidget is a desktop widget that shows your computer's own measurements. It doesn't collect personal data, has no accounts, no ads, no analytics and no telemetry. Everything it measures stays on your computer.

What stays on your computer

  • Your settings, in %APPDATA%\SysWidget\SysWidget.ini (or next to SysWidget.exe for a portable copy).
  • Downloaded translations, in %APPDATA%\SysWidget\lang.
  • The measurements themselves (CPU, GPU, FPS, memory, network, disks, battery). SysWidget reads them from Windows and shows them; it doesn't store or send them anywhere.
  • "Now playing" reads the song title, artist and cover from Windows' media controls only to show them in the widget.
  • "Show in games through RivaTuner" passes text to RivaTuner Statistics Server on the same computer, through Windows shared memory.

Connections SysWidget makes

SysWidget only connects to other systems for these features. Each one is visible in the app and can be turned off.

  • Update checks (Settings → General → Check for updates, on by default): about every 6 hours SysWidget asks GitHub for the latest release of this project (api.github.com) and for the current translation file of your language (raw.githubusercontent.com). The requests contain only what any web request does (your IP address, which GitHub sees) and SysWidget's version number. Turn the setting off and SysWidget makes no update or translation requests.
  • Installing an update: only when you click Update now, SysWidget downloads the release zip from github.com.
  • Ping (off by default): while the Ping section is shown, SysWidget sends a standard network ping about once a second to the server you choose: Cloudflare (1.1.1.1), Google (8.8.8.8), your router, or an address you enter. A ping carries no personal data.
  • Links: the project and donation links in the menu open in your web browser only when you click them.

Requests to GitHub are covered by GitHub's privacy statement, and pings by the policy of the server you choose. SysWidget's developer doesn't receive any of this data.

This website
