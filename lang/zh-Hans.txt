# ---- How to use
tips.title = 如何使用 SysWidget

tip.right = 打开菜单。其他选项都在设置中。

tip.hover = 查看哪些应用占用最多。
tip.island.k = 指向迷你模式
tip.island = 灵动岛会展开：图表、占用最高的应用、专辑封面和播放按钮。
tip.ctrl.k = 按住 Ctrl

tip.tray = 单击可隐藏或显示小组件。
tip.keys.k = Ctrl + Alt + W

tip.media.k = 正在播放
