# ---- How to use
tips.title = SysWidget の使い方
tip.drag.k = ドラッグ
tip.drag = ウィジェットを移動します。画面の端に吸着します。
tip.dbl.k = ダブルクリック
tip.dbl = タスク マネージャーを開きます。
tip.right.k = 右クリック
tip.right = メニューを開きます。その他は設定にあります。
tip.hover.k = CPU やメモリをポイント
tip.hover = 使用量の多いアプリがわかります。
tip.island.k = ミニモードをポイント
tip.island = アイランドが広がり、グラフ、負荷の高いアプリ、アルバムアート、再生ボタンを表示します。
tip.ctrl.k = Ctrl を押したまま
tip.ctrl = クリックを透過するときやカーソルの下で隠れるときにウィジェットを操作できます (メニューの「ウィジェット上のマウス」)。
tip.tray.k = トレイ アイコン
tip.tray = クリックでウィジェットの表示/非表示を切り替えます。
tip.keys.k = Ctrl + Alt + W
tip.keys = どのアプリからでもウィジェットを表示/非表示にします。Ctrl + Alt + M でミニモードを切り替えます。
tip.media.k = 再生中
tip.media = 設定でオンにすると、再生中の曲や動画を表示し、ウィジェットから一時停止やスキップができます。
tips.ok = OK
